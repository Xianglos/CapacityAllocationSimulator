
## 一、系统目标（明确版）

构建一个**月度生产演算系统**，用于：

1. 输入生管提供的**整月 Lot 产量**；
2. 在品种、工序、设备、区域、出勤率、加工时间、区域可加工性、优先级等约束下，进行**整月产能验算**；
3. 分配原则：**先把所有设备产能排满**，再判断是**富余**还是**缺口**；
4. 输出结论：
   - 有富余 → 可完成月度指标；
   - 有缺口 → 无法完成指标，输出**缺口 Lot 数**；
5. 输出**桑基图**：品种 → 工序 → 设备 → 区域 → 最终完成 / 缺口。

---

## 二、输入数据

### 1. 生产需求（生管提供）
- 月度 Lot 清单
- 每个 Lot：
  - Lot 编号
  - 品种
  - 数量（Lot 为最小单位，**不可拆分**）
  - 手动设定的**粗优先级**（标记重要/紧急，优先生产）
  - 交期（可选，辅助排序）

### 2. 基础主数据（数据库输入）
| 数据项 | 说明 |
|---|---|
| 品种 | 品种清单 |
| 品种-工序路线 | 每个品种经过的工序顺序 |
| 工序-设备对应 | 每道工序可由哪些设备加工 |
| 设备-区域归属 | 每台设备属于哪个区域 |
| 设备出勤率 | 入库，按设备设定，单位分钟口径 |
| 品种-工序加工时间 | 随品种变化，单位分钟/Lot |
| 品种-区域可加工性 | 某些品种只能在指定区域生产 |
| 优先级 | 手动粗优先级，用于排序 |

### 3. 时间口径
- 统一使用**分钟**
- 月度设备可用工时 = 月度日历分钟 × 设备出勤率
- 工序需求工时 = 该工序 Lot 数 × 该品种该工序单 Lot 加工时间（分钟）

---

## 三、约束条件（明确版）

1. **Lot 不可拆分**：一个 Lot 只能整体分配到某台设备/某个区域，不能拆到多台设备。
2. **工序顺序**：Lot 必须按品种工艺路线依次经过各工序。
3. **设备约束**：每道工序只能由对应设备加工。
4. **区域约束**：设备属于区域；品种只能在允许的区域加工。
5. **出勤约束**：设备月度可用分钟 = 日历分钟 × 出勤率。
6. **加工时间约束**：随品种变化，单位分钟/Lot。
7. **优先级约束**：手动粗优先级高的 Lot 优先占用产能。
8. **产能约束**：设备/区域月度可用分钟有限，先排满。

---

## 四、核心计算逻辑（明确版）

### 1. 需求展开
- 按品种展开每个 Lot 的工序路线；
- 每道工序生成需求：Lot 数 × 单 Lot 加工时间（分钟）；
- 根据品种-区域可加工性，过滤可选区域及区域内设备。

### 2. 产能计算
- 每台设备：月度可用分钟 = 日历分钟 × 出勤率；
- 每个区域：区域可用分钟 = 区域内设备可用分钟汇总。

### 3. 分配与排满
- 按**手动优先级**排序 Lot（高优先级先排）；
- 对每个 Lot 的每道工序：
  - 在允许的区域/设备中分配；
  - 优先排满设备产能；
  - Lot 不可拆分，整 Lot 分配到一台设备；
  - 若设备剩余产能不足以容纳整 Lot，则尝试下一台可用设备/区域；
- 记录每个设备/区域的已用分钟、剩余分钟。

### 4. 富余 / 缺口判断
- 所有 Lot 全部分配成功 → **有富余**，输出富余产能（分钟/Lot 当量）；
- 存在无法分配的 Lot → **有缺口**，缺口 = **无法完成的 Lot 数**；
- 缺口可按设备/区域/工序/品种维度汇总（辅助分析）。

---

## 五、输出要求（明确版）

### 1. 验算结论
- 月度总需求 Lot 数 vs 可完成 Lot 数
- 结论：**有富余（可完成指标）** / **有缺口（无法完成指标）**
- 缺口 Lot 数（总数 + 分维度明细）
- 富余产能（若有）

### 2. 桑基图
固定层级：

**品种 → 工序 → 设备 → 区域 → 最终完成 / 缺口**

展示内容：
- 每个品种的 Lot 流经各工序、设备、区域的分配量；
- 最终流向“完成”的 Lot 数；
- 无法分配的 Lot 流向“缺口”；
- 直观看出瓶颈设备/区域/工序。

### 3. 辅助输出（建议）
- 设备/区域利用率（已用分钟 / 可用分钟）
- 瓶颈设备/区域清单
- 缺口按品种/工序/设备/区域明细
- 优先级对分配结果的影响（高优先级 Lot 完成情况）
